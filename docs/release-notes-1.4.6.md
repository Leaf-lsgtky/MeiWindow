- **修复：收藏区应用与功能无法混排**：此前已选功能（聚合支付、应用快捷方式等）只能排在所有收藏应用之后，功能收藏也只能在功能段内拖动。现在应用与功能共用一张收藏顺序表，可以把功能拖到应用前面，也可以把应用拖到功能后面，原有长按拖动、让位动画和拖拽浮层保持不变。
- **同步：混排顺序跨进程生效**：设置页、SystemUI 的「更多应用」面板和扇形底部栏都按同一份 `pinned_order` 布局显示；面板里调整后设置页同步，设置页调整后面板/扇形同步。
- **兼容：旧收藏数据不丢**：没有混排布局的旧数据仍按「应用在前、功能在后」显示；布局缺失或新增收藏会自动补到末尾，不会少收藏。
- **说明**：
  - 从 1.4.5 升级无需额外操作；
  - 若此前安装过 debug 签名测试包，由于发布包使用正式签名，需先卸载旧版本再行安装
    （卸载会清理配置与 LSPosed 勾选状态）。
