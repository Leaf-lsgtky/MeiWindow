- **重构：设置界面整体换成 Miuix 页面骨架**：底栏固定为「首页 / 功能 / 设置」三页，原单页设置拆成一整套二级页（触发手势与区域、扇形面板、更多面板与列表、轻量打开、Flyme 小窗、主题外观、模块运行诊断、关于）。所有页面统一渐进模糊顶栏、滚动收尾触感、宽屏内容居中与横屏缺口补偿；底栏支持贴底与悬浮玻璃两种形态。
- **重构：首页状态卡片**：换成 KernelSU / HyperMusicCover 的版式 —— 左上标题 + 副行（框架与版本）、左下角应用名、右下角出血的超尺寸状态图标，卡内铺一层 InstallerX 式流体光效并在绿/红两套状态色间流动；卡片补上 12dp 水平间距，文字改用中性内容色，按下有 Tilt 回弹。
- **新增：关于页独立成二级页**（设置 → 关于魅窗，不占底栏）：OS3 流光背景（AGSL RuntimeShader，四团颜色缓慢漂移）、hero 三段视差淡出、logo 与标题的 textureBlur 光扫、跟随背景一起糊的玻璃卡片；顶栏静止时全透明、完全透出流光，滚到底才渐显模糊与「关于」标题。
- **修复：关于页无法上下滑动**：`MiuixScrollBehavior` 的 `heightOffsetLimit` 默认是 `-Float.MAX_VALUE`，`SmallTopAppBar` 只有收到 `scrollBehavior` 才会把它归零，之前所有上滑都被顶栏的 nested-scroll 吃掉；已接上并补齐页面内容。
- **修复：轻量打开的小窗避让**：新增 avoid-target 过滤，`MiuiFreeFormManagerService` 选「上一个应用」当小窗避让目标时会校验包名与任务可用性，避免拿已经不在栈里的任务做避让导致小窗落位异常。
